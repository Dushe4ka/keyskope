# KeyScope

Веб-интерфейс для проверки API-ключей LLM-провайдеров.

## Требования

- Python 3.10+
- pip

## Установка и запуск

### Windows

Открой PowerShell в папке проекта и выполни:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m main
```

Если PowerShell запрещает активацию виртуального окружения, можно выполнить:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### Linux

Открой терминал в папке проекта и выполни:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m main
```

Если модуль `venv` не установлен, для Ubuntu/Debian выполни:

```bash
sudo apt install python3-venv
```

### macOS

Открой терминал в папке проекта и выполни:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m main
```

## Использование

После запуска открой в браузере:

**http://127.0.0.1:8000**

Для остановки сервера нажми `Ctrl+C` в терминале.

### Как это работает

- **Один ключ** — вставь ключ и нажми «Проверить». В режиме «Автоопределение»
  ключ параллельно прогоняется по всем провайдерам авторизационным запросом;
  определяется точный провайдер, активность ключа и баланс (где API его отдаёт).
  Провайдера можно выбрать и вручную.
- **Список ключей** — вставь несколько ключей (по одному в строке, можно
  вперемешку от разных провайдеров) и проверь все разом. Выводится сводка
  (активные/неактивные) и результат по каждому ключу.

Определение провайдера построено не на угадывании по виду ключа, а на реальном
ответе API — поэтому ключи любой структуры распознаются корректно.

## Примечание

- Результаты проверки зависят от API и прав доступа конкретного провайдера.
- **Определение провайдера и активности** не тратит деньги: шлётся запрос с
  несуществующей моделью, который проверяет только авторизацию.
- **Баланс**:
  - Где есть API точного баланса (OpenRouter, DeepSeek) — показывается сумма.
  - У остальных (OpenAI, Google, Groq, Mistral и т.д.) публичного API баланса
    нет. Поэтому наличие средств проверяется **реальным мини-запросом генерации**
    (`max_tokens=1`, модель берётся из списка моделей ключа). Это **платно** —
    микросписание (доли цента) с ключа при каждой проверке. Результат:
    «Есть» (запрос прошёл, точная сумма недоступна) или «Пусто» (отклонён из-за
    квоты/оплаты). В массовом скане это повторяется для каждого активного ключа.
